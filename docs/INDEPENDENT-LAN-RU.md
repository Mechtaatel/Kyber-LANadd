# Подключение к Galactic Assault [Ru] через Radmin

1. Используйте KYBER Launcher LAN ADD 1.8.3 или новее. Для исправления входа достаточно обновить модуль на сервере; переустановка клиента не требуется.
2. Подключитесь в Radmin VPN к сети `Battlefront Kyber II`. Адрес сервера — `26.63.88.76`.
3. Войдите в свою EA-учётную запись в лаунчере. Нужна приобретённая Battlefront II и моды коллекции BF Plus Only.
4. Обновите список серверов и выберите `Galactic Assault [Ru]` с отметкой LAN. Допуск выдаёт сам сервер через Radmin; токен, список серверов, прокси и голосовой сервис Kyber для этого входа не нужны.

Если Kyber API недоступен, в 1.8.3 выберите **LAN — WITHOUT KYBER SERVICES** на экране входа EA. В новых исходниках лаунчера также предусмотрен автоматический переход после ограниченного ожидания. Для явного запуска без Kyber можно использовать `Start-LAN.cmd` из комплекта. При переходе из уже запущенной обычной игры сначала закройте Battlefront II.

Чтобы вернуться из принудительного LAN-режима в публичный Kyber, закройте игру и лаунчер и запустите `kyber_launcher.exe` напрямую.

Официальный лаунчер продолжает работать через публичный список Kyber. Независимый LAN-вход поддерживается выпущенной LAN ADD 1.8.3: выберите именно строку с регионом LAN. Доступность самого Radmin, EA и совпадение модов по-прежнему необходимы.

LAN не подтверждает Kyber ID. Права администратора не выдаются по одному нику: для учёта регистрации и ролей используется подтверждение игровой сессии через существующие команды бота.
