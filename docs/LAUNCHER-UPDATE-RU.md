# Обновление лаунчера LAN ADD

Закройте лаунчер и игру. Распакуйте весь комплект в отдельную папку и запустите
kyber_launcher.exe. Рядом с ним должны оставаться data, lan-module,
maxima-bootstrap.exe, maxima-service.exe и остальные файлы архива.
Папку с модами переносить не требуется.

В этой сборке:
- блок версии снова шириной 220 пикселей; LAN ADD показывает только номер;
- вводимый текст в поиске и других полях светлый;
- файлы модуля проверяются до запуска игры;
- при кириллице в пути модуль подготавливается в ASCII-каталоге
  ProgramData/Kyber/LAN-Modules с проверкой контрольных сумм;
- включены Maxima, LAN-модуль и библиотеки Visual C++ x64.

Если модуль по-прежнему не запускается, сохраните новые логи: строка
Game module указывает выбранный путь, версию и число выбранных модов.
Предыдущий лог подтверждал наличие 72 модов, но локальный интерфейс DLL
во время LAN-запусков не отвечал. Успешный запуск на том ПК ещё нужно проверить.
